Install

Tapbar isn’t on the Play Store, so Android may block it. Open the fix that matches.

Play Protect blocks the install

Play Protect may flag Tapbar because it uses Accessibility and Overlay permissions. To install anyway:

  • Open the Play Store and tap your profile icon.
  • Tap Play Protect, then the Settings gear.
  • Turn off Scan apps with Play Protect and Improve harmful app detection.
  • Install Tapbar, then turn these back on.

Swipe sideways to see every step.

“Restricted setting” when enabling permissions

Newer Android versions block permission toggles for sideloaded apps. To fix it:

  • Long press the Tapbar icon and open App info.
  • Tap the three-dot menu and choose Allow restricted settings.
  • Enable the Accessibility and Overlay permissions in Tapbar.
